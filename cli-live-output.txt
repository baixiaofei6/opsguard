===== 1) opsguard --help =====
usage: opsguard [-h] [--config CONFIG] [--no-color]
                {diagnose,explain,fix,rollback,audit,backend,doctor,install-local,integrate}
                ...

OpsGuard - 可证明安全的 Windows 运维 CLI（诊断/报告解读/带回滚修复）

positional arguments:
  {diagnose,explain,fix,rollback,audit,backend,doctor,install-local,integrate}
    diagnose            ① 报错排障：只读诊断，给结论和建议
    explain             ② 报告解读：脱敏→AI后端→回填→展示
    fix                 ③ 带回滚修复：诊断→AST→确认→备份→执行→哈希
    rollback            按 manifest 独立回滚 + 三方哈希验证
    audit               查审计日志
    backend             查看/选择 AI 后端状态
    doctor              环境自检
    install-local       本地模型安装(官方链接+确认+sha256)
    integrate           为既有项目生成 --ai 补丁(默认不写回)

options:
  -h, --help            show this help message and exit
  --config CONFIG       指定配置文件路径
  --no-color            关闭彩色输出
